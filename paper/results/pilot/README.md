# Pilot Results

This directory stores cleaned paper-facing copies of retained pilot evidence.
Rows here are useful for diagnostics, appendix planning, and plotting scripts,
but they are not paper-grade evidence for final quality claims unless the file
states that it uses the required evaluation setting.

`cifar10_pndm_euler_pilot_fid.csv` is generated by
`paper/figures/src/plot_cifar10_pndm_pilot.py` from
`outputs/gpde_pndm_test/metrics/gpde_pndm_test.csv`.
