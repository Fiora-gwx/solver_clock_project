# CIFAR-10 50k Results

This directory stores cleaned paper-facing copies of the PNDM/CIFAR-10 50k FID
runs for seeds 0, 1, and 2, including base, native-coordinate linear, fixed
Karras/EDM-style, authorized project-owned offline, and D-GPDE schedules.

- `cifar10_pndm_euler_50k_fid_seed0.csv`: legacy seed-0 cleaned FID rows
  generated by `paper/figures/src/plot_cifar10_pndm_pilot.py`.
- `cifar10_pndm_euler_50k_fid_detail_seeds0_1_2.csv`: cleaned per-seed rows
  generated by `paper/figures/src/aggregate_cifar10_pndm_50k.py`.
- `cifar10_pndm_euler_50k_fid_aggregate_seeds0_1_2.csv`: mean, standard
  deviation, and standard error by NFE and method.
- `cifar10_pndm_euler_50k_fid_delta_seeds0_1_2.csv`: paired base-minus-D-GPDE
  reductions and D-GPDE-minus-authorized-offline gaps by NFE. The aggregate
  CSV also contains the native-coordinate linear and Karras-style baselines.
- `cifar10_pndm_euler_nfe20_schedule_profile_seed0.csv`: source rows for the
  NFE-20 schedule-profile diagnostic figure.
- `cifar10_pndm_euler_50k_reuse_seed0_schedule_detail.csv`,
  `cifar10_pndm_euler_50k_reuse_seed0_schedule_aggregate.csv`, and
  `cifar10_pndm_euler_50k_reuse_seed0_schedule_rounding.csv`: actual
  generation reuse check in which the seed-0 D-GPDE schedule is loaded for
  seeds 1 and 2 at NFE 10 and 20. The rounded PNDM Euler execution timesteps
  match the seed-specific schedules for these rows.
- `cifar10_pndm_euler_50k_oracle_reuse_cost_seed0.csv` and
  `cifar10_pndm_euler_50k_oracle_reuse_cost_seeds1_2.csv`: calibration cost
  and oracle reuse accounting copied from the run outputs.
- `cifar10_pndm_euler_50k_schedule_nfe*_seed*.json`: copied D-GPDE schedule
  metadata.
- `cifar10_pndm_euler_50k_linear_schedule_nfe*_{meta.json,timesteps.npy,time_grid.npy}`:
  copied native-coordinate linear schedule metadata and arrays.
- `cifar10_pndm_euler_50k_karras_schedule_nfe*_{meta.json,timesteps.npy,time_grid.npy,sigmas.npy,sigma_grid.npy}`:
  copied fixed Karras/EDM-style schedule metadata and arrays.
- Authorized offline metric rows are included in the aggregate CSVs. The
  paper-facing artifact package omits authorized offline numeric schedule
  bundles under the AYS numeric schedule policy.
- `cifar10_pndm_euler_50k_offline_proxy_{detail,aggregate}.csv` and
  `cifar10_pndm_euler_50k_offline_proxy_schedule_nfe*_{meta.json,timesteps.npy,time_grid.npy}`:
  retained failed lightweight project-owned offline-proxy baseline. This is
  not the published AYS schedule.

The seed-0 figure/table are retained for provenance. The paper-facing aggregate
figure/table are generated by:

```bash
export PYTHONDONTWRITEBYTECODE=1
PY=/path/to/sc-diff/bin/python
$PY paper/figures/src/aggregate_cifar10_pndm_50k.py
$PY paper/figures/src/aggregate_cifar10_reuse_validation.py
$PY paper/figures/src/aggregate_cifar10_offline_proxy.py
$PY paper/figures/src/plot_cifar10_schedule_profile.py
```
